# Contents

- `build.mjs` runs the same production generation through Vite 7.3.6 and 8.2.1, verifies receipts and rejection controls, and renders the emitted SSR module.
- `src/` contains the hydrated package consumer, independent second entry, lazy module, SSR-only recipe, and nested compiler foundation.
- `type-contract.ts` checks the public adapter against each installed Vite declaration set.
- `toolchain.ts` pins Vite and its actual Rollup/Rolldown engine independently and binds both native output hooks to that qualification row.
- `diagnostics.ts` caps process diagnostics while preserving exact first and last bytes.
- `browser-endpoint.ts` validates the pinned browser server's exact IPv4 loopback WebSocket endpoint without rewriting it.
- `browser-control.ts` binds a genuine Node 24 browser worker to its request and collected-resource receipt; Bun retains the compiler and HTTP coordinator.
- `browser-worker.ts` runs every Playwright server, connection, context, and native assertion together in Node 24, with real pending-acquisition and connected cancellation seams.
- `custody.ts` coordinates cancellation, late resource acquisition, positive process-group collection, and durable matrix receipts.
- `cancellation-owner.ts` is the isolated native signal-regression owner, not a production consumer entry.
- `cancellation-supervisor.ts` exercises cancellation while a nested owner's readiness is pending.

# Guidelines

- Use the packed public package. Do not import repository source or replace the compiler, adapter, runtime, or generation finalizer.
- Keep this fixture production-only. Qualify both the default map-disabled profile and the adapter-owned external-map profile on each pinned engine, using the same installed packed package. Verify native client, lazy and SSR maps from the final published directory against exact loaded source bytes. Hidden, inline, copied, caller-enabled and late-mutated maps must fail without a complete graph receipt.
- Cover Vite 7.3.6/Rollup 4.63.1 and Vite 8.2.1 with both Rolldown 1.2.7 and 1.2.8. Pin transitive engine resolution; a Vite version alone does not identify the native bundler.
- Keep both client entries, the lazy import, native interaction, independent SSR graph, nested foundation, and one finalized package/caller union observable.
- Run the matrix only through the repository's exclusive validation scheduler. Retain failed evidence and close every owned browser, server, and child process.
- Own pending browser acquisitions before awaiting them. Treat uncertain group collection as failure, and retain evidence on cancellation. Publish the success receipt outside disposable consumers only after all pinned rows and all resource collection pass.
- Keep Playwright server and client operations in the same genuine Node 24 worker. Do not restore Bun-hosted browser control, rewrite endpoints, increase browser deadlines, or treat worker exit alone as collection proof. Require the request-bound worker receipt and positive Chromium-group absence.
- Run the native cancellation regressions through the exclusive scheduler with a real installed browser. The pure custody tests do not start child processes or browsers.
